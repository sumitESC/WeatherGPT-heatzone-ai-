# WeatherGPT Dashboard (HeatZone Frontend)

> **Module Role in WeatherGPT**: Interactive geospatial dashboard for visualizing the 30-day (720-hour) multi-variable forecasts generated by the WeatherGPT Temporal Fusion Transformer (TFT) model. It displays heat risk analytics, Sentinel-2 satellite telemetry, historical ERA5 climate trends, and embeds the conversational AI assistant for natural language querying across 75+ cities in Uttar Pradesh.

---

## 1. Abstract

The `heatzone-frontend` is a production React 18 application built with Vite, TypeScript, and Tailwind CSS. It acts as the visual analytics layer for the WeatherGPT system, consuming data from the HeatZone ML API. The dashboard allows stakeholders—disaster managers, urban planners, agricultural officers—to visually explore the 35 forecasted weather variables (up to 30 days ahead), track real-time heat risk scores (0-100), analyze Sentinel-2 environmental indices (NDVI, NDWI, NDBI), and interact directly with the LLM-powered WeatherGPT chatbot.

## 3. Key Pages & Visualizations

### 3.1 Dashboard (`Dashboard.tsx`)
The main overview page displaying:
- **City Grid**: 75 city cards with live heat risk scores (0–100), zone badges (🟢🟡🟠🔴), and current Open-Meteo temperature readings.
- **Alert Summary**: Active severe weather alerts based on TFT forecast thresholds (heatwave, heavy rain, high winds).

### 3.2 Forecast 30-Day Explorer (`Forecast.tsx`)
Dedicated visualization for the TFT model outputs:
- **Multi-horizon charts**: Recharts-powered graphs displaying 720 hours of predictions for Temperature, Precipitation, Humidity, and Wind.
- **Quantile Uncertainty**: Visualizes the probabilistic bounds (e.g., P10, P50, P90 quantiles) inherent in the TFT's pinball loss training, showing how forecast uncertainty widens over the 30-day horizon.

### 3.3 City Detail (`CityDetail.tsx`)
Deep-dive analytics for a single city:
- **Satellite Telemetry**: Displays Sentinel-2 indices (NDVI, NDWI, NDBI) used as static inputs by the TFT static encoder.
- **Heat Risk Decomposition**: Breaks down the Random Forest heat score into primary drivers (e.g., "Concrete Density" or "Vegetation Scarcity").

### 3.4 Interactive Map (`MapPage.tsx`)
React-Leaflet geospatial visualization:
- **Heat Risk Overlay**: Color-coded city markers across Uttar Pradesh based on real-time heat risk scores.
- **Click-to-Detail**: Navigate directly to the City Detail view from map pins.

### 3.5 Embedded AI Chatbot (`Chatbot.tsx`)
The embedded React component for the WeatherGPT conversational engine:
- **Sense-Layer Integration**: Users can ask "Will it rain next week?" The chat queries the backend's TFT forecast, injects the numbers into the LLM context, and replies in natural language with 0% numerical hallucination.
- **Voice Support**: Integrated Web Speech API for voice queries with barge-in capability.

## 5. Sample Data Flow: Forecast Visualization

When a user opens the Forecast page for Lucknow, the dashboard fetches the TFT model output:

```json
{
  "city": "Lucknow",
  "forecast": [
    {
      "timestamp": "2026-09-24 14:00:00",
      "pred_temperature_2m": 34.2,
      "pred_precipitation": 0.0,
      "heat_risk_score": 72.4,
      "heat_zone": "HIGH"
    }
    // ... up to 720 hours
  ]
}
```
The React frontend then parses this array and renders an `AreaChart` for temperature bands and a `BarChart` for hourly precipitation timelines.

## 6. Setup & Deployment

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build
```

**Environment Variables (`.env`)**:
```env
VITE_API_BASE_URL=https://heatzone-backend.onrender.com
VITE_GROQ_API_KEY=your_groq_api_key
VITE_GROQ_MODEL=llama3-70b-8192
```

The frontend is optimized for static deployment on platforms like Render, Vercel, or Cloudflare Pages.
